# Adam Bakery & Pastry Website

A warm, bilingual website concept for a neighbourhood bakery in Muscat, Oman, with a browsable menu, an order basket and branch locations.

## Live preview

https://shahinalambd.github.io/adam-bakery-website/

## Key features

- English / Arabic toggle with full RTL layout
- Menu page with category tabs, search and favourites
- Order basket drawer with quantities, pickup/delivery choice and branch selection
- Hero slideshow, scrolling ticker and favourites rail
- Branch cards with switchable embedded Google Maps
- Scroll reveal animations that respect reduced-motion settings
- Fully responsive, mobile-first layout

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
